# Школьный сайт 9Г класса / School Website for Class 9G

## 🇷🇺 Русский

### Описание
Сайт для отображения расписания уроков и домашних заданий 9Г класса. Включает в себя админ-панель для управления домашними заданиями.

### Функции
- Отображение расписания на всю неделю
- Просмотр домашних заданий
- Админ-панель для добавления домашних заданий
- Автоматическое обновление данных в реальном времени

### Как использовать
1. Откройте сайт
2. Для просмотра расписания и домашних заданий используйте главную страницу
3. Для входа в админ-панель:
   - Нажмите кнопку "Вход"
   - Введите код доступа: 123
   - В админ-панели выберите день недели и урок
   - Добавьте домашнее задание

## 🇬🇧 English

### Description
Website for displaying the schedule and homework assignments for Class 9G. Includes an admin panel for managing homework.

### Features
- Full week schedule display
- Homework viewing
- Admin panel for adding homework
- Real-time data updates

### How to Use
1. Open the website
2. Use the main page to view schedule and homework
3. To access the admin panel:
   - Click "Вход" (Login)
   - Enter access code: 123
   - In the admin panel, select day and lesson
   - Add homework

## Technical Details

### Files Structure
- `index.html` - Main page
- `styles.css` - Styling
- `script.js` - Functionality
- `data/schedule.json` - Schedule data

### Development
To run locally:
1. Clone the repository
2. Open index.html in a web browser
3. For development, use a local server to avoid CORS issues with JSON loading
